# IncidentIQ

IncidentIQ is an incident investigation and intelligence platform for software engineers.

It connects application telemetry, incident signals, engineering changes, historical incidents, and AI-assisted investigation into a structured evidence-backed workflow.

## Tech Stack

- React + TypeScript
- FastAPI
- PostgreSQL
- Redis
- Python Worker
- pgvector
- Docker

## Project Structure

- `backend/` — API and backend application
- `frontend/` — React frontend
- `worker/` — asynchronous processing
- `infrastructure/` — infrastructure configuration
- `docs/` — architecture and product documentation
- `scripts/` — development and data-generation scripts
